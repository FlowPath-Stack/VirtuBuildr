## 🐸 CROAKFALL: Pond Wars (prototype)

A playable 3D multiplayer frog game prototype lives in this repo:

- **Play offline (bot frogs):** open [`game/index.html`](game/index.html) in a browser — no install, no build step.
- **Play multiplayer:** `cd server && npm install && npm start`, then open the game in two or more tabs.
- **Design & roadmap:** see [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md).

Controls: **WASD** hop · **Space** big jump · **Click** tongue-snap a fly · **C** croak · **E** talk to NPCs.

Featuring the "Great Croak" story quest chain from Elder Toad, and hats & upgrades at Madame Bufo's Bazaar.
